# Atlas Relay

Atlas Relay delivers product events to the systems your team depends on. Start with the [quickstart](/quickstart), then learn how [Event Destinations](/concepts/event-destinations) and the [delivery lifecycle](/concepts/delivery-lifecycle) work.

Use the guides to configure destinations, verify signatures, test deliveries, and handle failures safely.

# Quickstart

Install the CLI and sign in:

```bash
npm install --global @atlas-relay/cli
atlas auth login
```

Create an Event Destination for your application:

```bash
atlas destinations create \
  --name quickstart-events \
  --endpoint https://example.com/atlas/events
```

Store the returned signing secret, then send a sample event. For delivery options, see [Configure an Event Destination](/guides/event-destinations).

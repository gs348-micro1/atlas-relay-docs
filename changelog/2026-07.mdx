# July 2026

## Event Destinations are generally available

Event Destinations became generally available on July 8, adding configurable filters, retry policies, and per-attempt delivery history.

## Classic Webhooks retirement

Classic Webhooks were retired on July 31. Existing endpoints were migrated to Event Destinations, and the `atlas webhooks` command group was removed from the CLI. Use `atlas destinations` commands for all destination management.

## Delivery history retention

Delivery attempt metadata is now retained for 30 days on all plans.

# Classic Webhooks (retired)

Classic Webhooks were retired on July 31, 2026. Existing endpoints were migrated to Event Destinations automatically, and the `atlas webhooks` command group was removed from the CLI.

To route events to an HTTPS endpoint, create an [Event Destination](/concepts/event-destinations):

```bash
atlas destinations create \
  --name billing-events \
  --endpoint https://example.com/atlas/events \
  --events invoice.created,invoice.paid
```

Follow [Configure an Event Destination](/guides/event-destinations) to get started, and see the [July 2026 changelog](/changelog/2026-07) for details about the retirement.

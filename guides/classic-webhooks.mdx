# Migrate from Classic Webhooks

Classic Webhooks were retired on July 31, 2026. Existing endpoints were migrated to Event Destinations, and the `atlas webhooks` command group was removed from the CLI.

Use [Configure an Event Destination](/guides/event-destinations) for current setup instructions and `atlas destinations` commands for destination management. Existing integrations should verify their migrated destination's endpoint, event filters, and signing secret before changing production traffic.

After migration, review [signature verification](/guides/signature-verification) and [destination retry policies](/guides/event-destination-retries).

# Classic Webhooks (retired)

Classic Webhooks were retired on July 31, 2026. Existing endpoints were migrated to Event Destinations automatically, and the `atlas webhooks` command group was removed from the CLI. Use `atlas destinations` commands for all destination management.

To configure event delivery, follow [Configure an Event Destination](/guides/event-destinations). After setup, review [signature verification](/guides/signature-verification).

For details about the retirement, see the [July 2026 changelog](/changelog/2026-07).

# CLI reference

## Authentication

- `atlas auth login` opens a browser sign-in flow.
- `atlas auth status` prints the active organization and environment.

## Event Destinations

- `atlas destinations create --name <name> --endpoint <url> --events <types>` creates a destination.
- `atlas destinations update <name>` updates destination settings such as the retry policy.
- `atlas destinations test <name> --event <type>` sends a test event to a destination.

## Events

- `atlas events send --type <type>` sends an event.
- `atlas events get <id>` retrieves event metadata.

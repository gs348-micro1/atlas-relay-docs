# Event Destinations

An Event Destination combines an HTTPS endpoint, signing secret, event filter, and retry policy so delivery behavior can be configured and observed in one place.

Each destination has its own delivery history and signing secret. Create and manage destinations with the `atlas destinations` command group or the Atlas Relay API.

Continue with the [Event Destinations guide](/guides/event-destinations) or review the [delivery lifecycle](/concepts/delivery-lifecycle).

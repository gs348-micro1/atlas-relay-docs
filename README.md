# Atlas Relay documentation

This repository contains the source for the Atlas Relay developer documentation.

## Local preview

Install the Mintlify CLI, then run `mint dev` from the repository root. Open pull requests for content or navigation changes; the deploy branch is protected.

## Content conventions

- Put user-facing pages in `docs.json` unless they are intentionally hidden.
- Preserve established routes when replacing retired product guidance.
- Use Event Destinations terminology and current `atlas destinations` CLI commands.
- Treat changelog entries as historical records rather than current instructions.
